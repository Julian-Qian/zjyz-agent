## 字段说明

- `建议项目范围`：ALL 为企业全部项目，MULTI 为用户选定多个项目，SINGLE 为唯一单项目。
- `预期状态`：是测试前的能力基线，不是执行结果。
- `支持级别`：FULL 为完整支持，PARTIAL 为部分支持，CONDITIONAL 为条件支持，NONE 为当前无可执行完整能力。
- `最小必需工具`：该问题获得事实答案所需的最小工具集合；不是分类工具全集。
- `预期能力/工具`：当前工具名或建议补齐的能力名；“待补/待建”代表审计缺口。
- `准确性判定要点`：评估 Agent 必须逐条验证，不允许仅以“回答流畅”判为通过。
